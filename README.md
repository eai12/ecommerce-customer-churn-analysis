# -
某电商平台近期客户流失率高达 40%。传统的挽留策略采用“一刀切”的群发优惠券，导致营销成本极高且效果极差。本项目旨在通过 SQL + Python 机器学习，设置高价值客户权重，提升高价值客户优先级，精准识别高风险流失客户，分析流失影响因素，制定精细化挽留策略，实现降本增效。

## 🛠️ 技术栈
- **数据提取与清洗**: MySQL (窗口函数、CTE、表结构转换)
- **探索性数据分析 (EDA)**: Python (Pandas, Seaborn, Matplotlib)
- **机器学习建模**: LightGBM, XGBoost, RandomForest (Scikit-learn)
- **可解释性分析**: SHAP (Shapley Additive exPlanations)
- 
## 🔍 核心业务发现 (SQL 洞察)
- 通过 SQL 窗口函数计算发现，虽然各价值分层客户流失率均在 40% 左右，但**高价值客户的流失损失 CLV 占比高达 96%**。
- 因此，后续模型训练中引入了基于客户价值的 `sample_weight` 惩罚机制，提高高价值客户权重，让模型重点捕捉高价值流失特征。

## 🧠 机器学习建模与深度评估
- **特征工程与筛选**：结合 Spearman 秩相关热力图与业务逻辑，剔除强共线性冗余特征，防止特征重要性被稀释，提升模型运算效率。
- **多模型基线对比**：搭建 LightGBM、XGBoost、随机森林、决策树四种模型的“打擂台”评估框架，最终 LightGBM 综合表现最优。
- **双重样本加权机制**：针对 8.5:1 的严重样本失衡，不仅采用 `scale_pos_weight` 进行数量平衡，更创新性地引入基于业务价值（CLV）的 `sample_weight` 自定义权重惩罚，**强迫模型将注意力集中在高价值流失客户身上**。
- **防过拟合与稳定性验证**：利用 `RandomizedSearchCV` 结合 L1/L2 正则化、行/列双重采样进行深度调优；通过 5 折交叉验证确认模型泛化能力，将过拟合差值（Gap）控制在极低水平。
- **核心性能表现**：LightGBM 最终 AUC 达 0.71，少数类（流失）F1-score 为 0.62，**召回率（Recall）提升至 68%**，成功为业务端输出高召回率的高危客户干预名单。

## 💡 SHAP 可解释性解析
通过 SHAP 蜂群图发现：
- `客服工单数` 和 `距上次购买天数` 是导致流失的最核心因素。
- 结合单用户归因（Force Plot），业务团队能直接给销售解释：“为什么系统预测这个高价值客户会流失”。

## 🎯 业务落地与产出
- 基于模型输出的预测概率，结合阈值调优（降至 0.35），将客户划分为“高危、中危、低危”。
- 输出《高意向跟进名单》，推动运营团队针对高危高价值客户进行 1v1 人工召回，大幅提升营销 ROI。
